# Mon Planning

Agenda unifié d'INDAR Coaching : Google Agenda (Human, IPMS, rendez-vous), coachés et séances fixes, tâches, congés, partage en lecture seule.

- Cette page ne contient aucune donnée ni aucune clé. Elle se connecte à l'appli Google Apps Script du compte coaching grâce à un lien de connexion personnel, gardé sur chaque appareil.
- `index.html` : l'application (une seule page).
- `manifest.webmanifest`, `icon.svg` : installation sur l'écran d'accueil du téléphone.
